视觉语言导航的评价取决于任务如何定义：沿指定路线到达、寻找描述中的物体、根据对话继续行动，分别需要不同的输入、输出与成功条件。本文梳理代表性数据集和动作空间，推导终点成功、路径效率与路线忠实度指标，并用可复算的轨迹例子解释这些指标之间的差异。

“先经过靠窗的餐桌，再穿过走廊，在书架旁停下。”如果智能体绕开餐桌，直接走到书架，它完成了多少任务？终点正确，运动也可能更高效，但指定的路线没有完整执行。再把指令换成“找到客厅窗边的那盏落地灯”，评价还要检查智能体是否认对了物体。

这两种情形说明，模型结构之前需要先确定任务协议：语言提供什么信息，策略能看到什么，动作如何执行，评测器依据什么判定成功。系列综述给出了研究版图，本篇进一步建立阅读数据集、模型实验和评测代码所需的共同定义。

一、任务定义与信息边界

1.1 语言条件下的闭环决策

设语言输入为 xxx，时刻 ttt 的观测为 oto_tot​，此前执行的动作为 a<ta_{<t}a<t​。一个通用的导航策略可以写成

at∼πθ(⋅∣x,o≤t,a<t).a_t\sim\pi_\theta(\cdot\mid x,o_{\le t},a_{<t}). at​∼πθ​(⋅∣x,o≤t​,a<t​).

πθ\pi_\thetaπθ​ 表示参数为 θ\thetaθ 的动作分布。观测可以包含 RGB、深度、朝向、局部候选等，但具体有哪些内容，必须由任务协议限定。策略执行一个动作后，环境产生新的观测；动作序列因此依赖实际经历，无法仅凭一句指令提前固定下来。

令环境状态为 sts_tst​，这一过程可抽象为

st+1∼T(⋅∣st,at),ot+1∼O(⋅∣st+1).s_{t+1}\sim\mathcal T(\cdot\mid s_t,a_t), \qquad o_{t+1}\sim\mathcal O(\cdot\mid s_{t+1}). st+1​∼T(⋅∣st​,at​),ot+1​∼O(⋅∣st+1​).

T\mathcal TT 是状态转移机制，O\mathcal OO 是观测机制。状态可能包括完整布局与机器人位姿，策略只取得其中允许观测的部分。这组表达式既能描述导航图上的移动，也能描述连续空间执行；差别在于状态、观测与动作的具体定义。

完成一次回合后，策略输出执行轨迹 PPP 和终止结果。目标指代任务还需要物体预测 y^\hat yy^​；交互任务可能允许追加求助动作，并使语言输入随对话更新。

1.2 策略输入、训练监督与评测真值

一个数据文件可能同时保存完整参考路线、终点、物体标注和相机位姿。这些字段具有不同用途，不能因为它们存在于文件中，就全部作为测试策略的输入。

二、数据集与任务能力

2.1 路线跟随：R2R、R4R 与 RxR

R2R（Room-to-Room）将室内扫描环境中的路线与自然语言对应起来。它的典型任务是从指定起点出发，依据逐步描述经过地标，并在目标附近停止。原数据包含 7,189 条路线，每条有三份描述，共 21,567 条指令；路线来自满足长度限制的最短路径采样。R2R

这一构造使“跟随参考路线”与“高效到达终点”经常具有一致方向，但两者在定义上仍有区别。如果模型只依赖终点词语或路线分布，也可能取得一定成功；成功率本身无法说明它使用了多少中间指令。

R4R（Room-for-Room）把两条端点相近的 R2R 路线通过连接路径组合，同时拼接语言描述。组合路线可能包含折返和非最短路段，要求模型保留先后顺序与中间地标。此时，到终点的捷径可能偏离指令，评测需要考虑整条参考路线。R4R

RxR（Room-Across-Room）进一步扩展语言与标注方式，包含英语、印地语和泰卢固语，并将词语时间与标注者的相机姿态对齐。它支持研究多语言泛化，以及语言片段与沿途视觉之间的联系。时间对齐提供了“说到这里时看向哪里”的线索，并不直接等价于逐词对应的物体分割真值。RxR

三者的关系可以从研究变量理解：R2R 建立基本的指令跟随任务；R4R 强化路线忠实度；RxR 扩展语言覆盖及视觉语言对齐。它们不是可以仅凭规模大小排列的难度等级。

2.2 目标寻找：REVERIE 与 SOON

路线描述通常依赖起点和行走方向。“离开房间后右转”换一个起点就可能失去意义；“客厅窗边、沙发左侧的落地灯”则主要描述目标及其环境关系。

REVERIE要求智能体寻找起点不可见的目标物体，并完成视觉指代。评测需要区分：是否停在能观察目标的位置，以及是否选择了正确对象。对于提供候选框的设置，核心输出是正确候选；对于直接预测框的设置，还要按照规定检查框的重合度。两种设置承担的检测与定位工作量不同。REVERIE

SOON强调与起点相对独立的目标描述，使用对象属性、对象关系、所在区域及邻近区域引导探索。例如，房间线索先缩小搜索范围，对象关系再区分具体目标。其定位评价检查预测方向是否落在目标框内，因此不能直接套用另一数据集的框检测规则。SOON

目标寻找允许智能体自行选择合理路线。若语言没有规定必须经过某处，就不能仅因为它未复现某一条示范路线而认定失败。参考路线在这类任务中可能服务于训练或效率计算，其角色应与路线跟随任务分别说明。

2.3 交互式导航：CVDN 与 HANNA

CVDN采集导航者与协助者的对话。其 Navigation from Dialog History（NDH）任务使用目标提示、已有对话和当前观测，预测接下来的行动。这里主要检验理解已有对话后的导航能力；“何时主动提问、如何生成问题”还需要相应的交互任务设计。CVDN

HANNA允许智能体请求帮助，并获得语言与视觉形式的辅助信息。因此，导航能力之外，还需要分析求助时机、次数、助手信息和交互预算。拥有更多外部辅助的策略，即使成功率更高，也不能据此认定其自主导航能力更强。HANNA

2.4 街景导航：Touchdown

Touchdown使用街景全景图，研究长距离语言导航与空间描述解析。其导航任务要求到达目标节点或邻接节点；Spatial Description Resolution（SDR）则根据语言，在图像中预测被指代的位置。后者的输出是像素坐标，评价尺度也随之改变。Touchdown

街景图来自现实采集，但在图中移动仍是仿真交互。该协议没有自动包含动态行人避让、交通规则或真实底盘控制。

三、动作空间与环境假设

3.1 导航图与全景候选

图导航将环境表示为加权图 G=(V,E)G=(V,E)G=(V,E)：节点对应可观察位置，边表示可通行连接。在常见的全景候选接口中，动作集合可抽象为

At=N(vt)∪{STOP},\mathcal A_t=\mathcal N(v_t)\cup\{\mathrm{STOP}\}, At​=N(vt​)∪{STOP},

其中 vtv_tvt​ 是当前节点，N(vt)\mathcal N(v_t)N(vt​) 是允许选择的邻接节点。策略选择一个候选后，环境把智能体移动到对应位置。

这是一种高层接口概括。原始 R2R 基线还包含转头、抬头、低头和受当前视野约束的移动；后续全景方法改变了观测和候选组织。使用同一个 R2R 数据集，不代表使用同一种动作接口。 R2R 模拟器与任务定义

已给出的连边至少提供了局部可通行性先验，节点间移动也屏蔽了沿途的低层控制过程。策略获取相邻候选，不等于已经获得整栋建筑的完整地图；这两种信息权限仍需分别记录。

VLN-CE 将路线执行放入连续三维环境。其原始低层动作包括前进 0.25 m0.25\,\mathrm m0.25m、左转 15∘15^\circ15∘、右转 15∘15^\circ15∘ 和停止。位置在连续空间变化，但动作集合仍然有限。VLN-CE

四、终点成功、路径效率与路线忠实度

4.1 距离、轨迹与符号约定

下文对单个回合使用：执行路径 P=(p1,…,pn)P=(p_1,\ldots,p_n)P=(p1​,…,pn​)、参考路径 R=(r1,…,rm)R=(r_1,\ldots,r_m)R=(r1​,…,rm​)、目标 g=rmg=r_mg=rm​，以及成功距离阈值 δ\deltaδ。d(u,v)d(u,v)d(u,v) 表示协议规定的最短可通行距离；图任务通常使用加权最短路，连续环境则依具体评测器确定。

隔墙的两点可能直线距离很小，可通行距离却很长。自行实现指标时，替换距离函数会改变任务含义。

对于由合法相邻图移动构成的路径，其长度为

L(P)=∑j=1n−1d(pj,pj+1).L(P)=\sum_{j=1}^{n-1}d(p_j,p_{j+1}). L(P)=j=1∑n−1​d(pj​,pj+1​).

4.2 NE、SR 与 OSR：终点和停止行为

导航误差 Navigation Error 衡量最终位置到目标的距离：

NE=d(pn,g).\mathrm{NE}=d(p_n,g). NE=d(pn​,g).

OSR=1N∑i=1N1 ⁣[min⁡jd(pi,j,gi)<δ].\mathrm{OSR}=\frac1N\sum_{i=1}^{N} \mathbf1\!\left[\min_j d(p_{i,j},g_i)<\delta\right]. OSR=N1​i=1∑N​1[jmin​d(pi,j​,gi​)<δ].

4.3 SPL：成功与最短路效率

令 ℓi\ell_iℓi​ 为起点到目标的最短路径长度，LiL_iLi​ 为实际执行长度。Success weighted by Path Length 定义为

SPL=1N∑i=1NSiℓimax⁡(ℓi,Li).\mathrm{SPL}=\frac1N\sum_{i=1}^{N} S_i\frac{\ell_i}{\max(\ell_i,L_i)}. SPL=N1​i=1∑N​Si​max(ℓi​,Li​)ℓi​​.

失败回合贡献零；成功回合再按长度效率加权。分母取最大值，使得因成功半径而提前停止、实际路程短于到精确目标的最短路时，得分仍不超过 1。该指标由导航评测建议提出。

例如，四个回合中三个成功，三条成功路径分别为对应最短路的 1、2、2 倍，那么

SR=34=0.75,SPL=1+1/2+1/2+04=0.50.\mathrm{SR}=\frac34=0.75, \qquad \mathrm{SPL}=\frac{1+1/2+1/2+0}{4}=0.50. SR=43​=0.75,SPL=41+1/2+1/2+0​=0.50.

因此 SPL 同时混合了成功与效率，不能把它直接解释成“平均绕路比例”。它满足 0≤SPL≤SR0\le\mathrm{SPL}\le\mathrm{SR}0≤SPL≤SR。若允许起点就是目标、最短长度为零，还必须遵循评测器的退化情况约定。

SPL 的效率基准是起终点最短路。对于明确要求经过中间地点的非最短路线，这个基准与指令忠实度可能冲突。

4.4 CLS：路径覆盖与长度匹配

Coverage weighted by Length Score 使用参考路径的全部位置。首先定义覆盖得分

PC(P,R)=1m∑k=1mexp⁡ ⁣(−d(rk,P)δ),d(rk,P)=min⁡jd(rk,pj).\mathrm{PC}(P,R)=\frac1m\sum_{k=1}^{m} \exp\!\left(-\frac{d(r_k,P)}{\delta}\right), \qquad d(r_k,P)=\min_jd(r_k,p_j). PC(P,R)=m1​k=1∑m​exp(−δd(rk​,P)​),d(rk​,P)=jmin​d(rk​,pj​).

每个参考位置都寻找执行路径中的最近位置。距离为零时贡献 1，距离增大时贡献衰减；δ\deltaδ 在这里控制衰减尺度。PC 为软覆盖分数，不是“经过了多少比例的节点”的硬计数。

然后用覆盖程度缩放参考路径长度，得到期望长度 EPL\mathrm{EPL}EPL，并构造长度得分：

EPL=PC(P,R) L(R),\mathrm{EPL}=\mathrm{PC}(P,R)\,L(R), EPL=PC(P,R)L(R),

LS=EPLEPL+∣EPL−L(P)∣,CLS=PC⋅LS.\mathrm{LS}=\frac{\mathrm{EPL}} {\mathrm{EPL}+|\mathrm{EPL}-L(P)|}, \qquad \mathrm{CLS}=\mathrm{PC}\cdot\mathrm{LS}. LS=EPL+∣EPL−L(P)∣EPL​,CLS=PC⋅LS.

长度项防止智能体通过大量无目的探索获得高覆盖。分子与分母均为长度，最终分数无量纲。这套定义来自 R4R 论文第 3.3 节。

CLS 中的最近点匹配没有显式要求先后顺序。因此，相同地点集合与相同长度的路径，即使访问顺序不同，也可能得到相同得分。顺序约束需要进一步引入序列对齐。

4.5 nDTW：保持顺序的轨迹对齐

Dynamic Time Warping（DTW，动态时间规整）将两条序列按顺序对齐，同时允许一个点对应另一条路径中的多个点。它从两条路径的起点开始，到两条路径的终点结束，中间不能把较晚的位置倒过来匹配到较早的位置。

令 Dk,jD_{k,j}Dk,j​ 表示参考前 kkk 个点与执行前 jjj 个点的最小累计代价：

Dk,j=d(rk,pj)+min⁡{Dk−1,j,Dk,j−1,Dk−1,j−1}.D_{k,j}=d(r_k,p_j)+ \min\{D_{k-1,j},D_{k,j-1},D_{k-1,j-1}\}. Dk,j​=d(rk​,pj​)+min{Dk−1,j​,Dk,j−1​,Dk−1,j−1​}.

初始化为 D0,0=0D_{0,0}=0D0,0​=0，其余边界 Dk,0=D0,j=+∞D_{k,0}=D_{0,j}=+\inftyDk,0​=D0,j​=+∞（k,j>0k,j>0k,j>0）。三项分别允许推进参考序列、推进执行序列或同时推进；最终 DTW(R,P)=Dm,n\mathrm{DTW}(R,P)=D_{m,n}DTW(R,P)=Dm,n​。

将其按参考点数与距离阈值归一化，再取负指数：

nDTW(R,P)=exp⁡ ⁣(−Dm,nmδ).\mathrm{nDTW}(R,P)= \exp\!\left(-\frac{D_{m,n}}{m\delta}\right). nDTW(R,P)=exp(−mδDm,n​​).

累计偏离越大，分数越低；完全匹配时为 1。mmm 是参考路径的采样点数，不能换成参考路程的米数。精确递推需要 O(mn)O(mn)O(mn) 时间；仅计算分数时可以用滚动行降低存储量。nDTW 论文及算法

按顺序对齐容纳了路径长度与采样的差异，但实现仍需固定距离函数、轨迹采样和归一化尺度。尤其在连续环境中，不能把一方的每帧位姿与另一方少数路点任意混用。

4.7 sDTW：成功与忠实度的联合统计

成功加权的 nDTW（sDTW，也写作 SDTW）先对每个回合相乘，再取均值：

sDTW=1N∑i=1NSi nDTWi.\mathrm{sDTW}=\frac1N\sum_{i=1}^{N} S_i\,\mathrm{nDTW}_i. sDTW=N1​i=1∑N​Si​nDTWi​.

它同时要求终点成功和路线匹配，失败回合贡献零。需要注意，总体 SR 与总体平均 nDTW 的乘积通常不等于 sDTW。指标定义

例如两个回合的 nDTW 为 0.9、0.7，只有第一个成功，则 sDTW 为 0.9/2=0.450.9/2=0.450.9/2=0.45；总体 SR 为 0.5、平均 nDTW 为 0.8，相乘却是 0.4。存在成功回合时，正确分解是

sDTW=SR×nDTW‾成功回合.\mathrm{sDTW}=\mathrm{SR}\times \overline{\mathrm{nDTW}}_{\text{成功回合}}. sDTW=SR×nDTW成功回合​.

4.8 各项指标的解释边界

指标 主要衡量内容 单独使用时遗漏的内容
NE 最终位置到目标的距离 是否按指定路线行动
SR 在规定条件下最终成功 绕路程度、中间地标与顺序
OSR 是否曾到过目标附近 是否能自主正确停止
TL / PL 实际路径长度 是否成功；越短不一定越好
SPL 成功与最短路效率 非最短指令路线的忠实度
CLS 参考路线覆盖与长度匹配 显式访问顺序、终点成功门槛
nDTW 有序轨迹匹配 严格成功条件、物体是否认对
sDTW 成功条件下的有序匹配 失败回合中取得的部分进展

CLS 和 nDTW 都把参考路线当作语言执行的代理。如果一句指令允许多条合理路线，单参考评价可能惩罚另一种有效执行。解释结果时，应同时查看语言、轨迹和参考标注，而非把几何匹配分数直接等同于完整语言理解。

5.2 Seen 与 unseen 的划分

在原始 R2R 中，训练和 val-seen 共享建筑环境，但使用不同任务；val-unseen 与 test 使用不同于训练的建筑。原论文给出的划分为：

划分 建筑关系 指令数 主要用途
train 61 个训练环境 14,025 参数学习
val-seen 与训练共享环境 1,020 已见环境中的任务泛化
val-unseen 独立的 11 个环境 2,349 未见环境验证与模型选择
test 独立的 18 个环境 4,173 隐藏目标的测试评价

数量依据 R2R 原论文；具体复现使用对应版本的划分文件。

换一条指令不会自动产生未见环境；在相同建筑里更换路线，也不等于跨建筑泛化。另一方面，反复使用 val-unseen 选择超参数后，它承担了模型选择作用，仍需要独立测试检验最终结果。

完整的 VLN 结果应回答三个层次的问题：是否完成任务，是否按照语言约束完成，以及为此使用了什么信息和执行代价。 数据集规定问题边界，动作空间规定决策责任，评价指标则决定哪些行为得到奖励。把这三者对齐，后续关于模型结构、策略学习与机器人部署的比较才有明确含义。
